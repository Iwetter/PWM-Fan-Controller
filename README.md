# PWM Fan Speed Controller Using a 555 Timer

An adjustable DC fan-speed controller built using a **555 timer**, **IRLZ44N N-channel MOSFET**, and a potentiometer-controlled timing network.

The project was designed to explore **pulse-width modulation (PWM)**, transistor switching, inductive-load protection, and practical circuit debugging.

## Project Overview

The goal of this project was to create a simple and efficient way to control the speed of a 5 V DC fan.

Instead of controlling fan speed by dissipating excess energy through resistive components, the circuit uses **PWM** to rapidly switch power to the fan ON and OFF.

The 555 timer generates the PWM control signal, while an IRLZ44N MOSFET acts as the electronic switch that controls current through the fan.

The fan speed is adjusted using a potentiometer that changes the behavior of the 555 timer's timing network.

## How It Works

### 555 Timer

The 555 timer generates the repeating signal used to control the fan.

Internally, the timer uses reference voltages at approximately:

* 1/3 VCC
* 2/3 VCC

Pins 2 and 6 monitor the voltage across the timing capacitor.

As the capacitor charges and discharges between these thresholds, the internal comparators and flip-flop change the state of the 555 timer output.

This repeated switching creates the PWM signal used by the circuit.

### Potentiometer and Duty Cycle

The potentiometer does not directly control the fan.

Instead, it changes the resistance of the timing network, which affects how quickly the timing capacitor charges and discharges.

Changing this timing changes the **duty cycle** of the PWM signal.

A higher duty cycle keeps the MOSFET ON for a larger percentage of each cycle, increasing the average power delivered to the fan and causing it to spin faster.

A lower duty cycle reduces the average power delivered to the fan and lowers its speed.

## MOSFET Switching Stage

The output of the 555 timer controls the gate of an **IRLZ44N N-channel MOSFET**.

The MOSFET acts as an electronic switch:

1. The 555 timer sends a PWM signal to the MOSFET gate.
2. When the MOSFET turns ON, current flows through the fan and through the MOSFET to ground.
3. When the MOSFET turns OFF, current through the fan is interrupted.
4. Repeating this process rapidly controls the average power delivered to the fan.

Using the MOSFET allows the low-power signal generated by the 555 timer to control the larger current required by the fan.

## Flyback Protection

Because the fan contains a motor, it behaves as an inductive load.

When current through an inductive load is suddenly interrupted, the motor can generate a voltage spike known as **back EMF**.

A diode is used across the fan to provide a safe path for this current and protect the MOSFET and other circuit components.

## Circuit Design

![Circuit Schematic](images/circuit-schematic.png)

The circuit can be viewed as two main functional sections:

**PWM generation**

`Potentiometer + Timing Network → 555 Timer → PWM Output`

**Power switching**

`PWM Output → MOSFET → Fan`

Although these sections may appear separated in a schematic, they are electrically connected through the 555 output, supply, ground, and motor connections.

## Challenges and Debugging

A major part of this project involved troubleshooting the physical circuit and improving its behavior.

| Problem                                  | Cause                                        | Solution                                                        |
| ---------------------------------------- | -------------------------------------------- | --------------------------------------------------------------- |
| Power module and components were damaged | Excessive voltage was accidentally applied   | Replaced the damaged power module and components                |
| Fan remained ON continuously             | MOSFET gate was floating                     | Added a pull-down resistor to stabilize the gate                |
| PWM control disappeared                  | Loose connection at the 555 timer            | Secured the IC and electrical connections                       |
| Fan had a limited speed-control range    | Timing resistor values were not optimal      | Increased resistance from 10 kΩ to 20 kΩ                        |
| Circuit was difficult to visually trace  | Dense breadboard wiring and schematic layout | Analyzed labeled nets and reorganized the circuit documentation |

These problems helped reinforce the importance of voltage limits, stable transistor gate states, reliable physical connections, and component-value selection.
